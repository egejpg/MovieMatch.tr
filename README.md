# MovieMatch.tr

#### Video Demo: https://youtu.be/YoVxHC91EzA
#### Description:
MovieMatch is a simple web application that helps groups quickly decide which movie is the most suitable.
The idea is straightforward the user selects two movies, and the system suggests a new movie that best matches the characteristics of both.

❔How It Works:

1-) The user selects two movies.

2-) Movie data is fetched using the TMDB API.

3-) The Gemini 2.5 Flash model analyzes both inputs and determines the closest matching movie.

4-) The recommended movie is displayed to the user


  

🛠️ Tech Stack:

Python (Flask) – Backend logic

JavaScript – Dynamic UI functionality

HTML, CSS, Bootstrap – Frontend and design

TMDB API – Movie lists and metadata

Gemini 2.5 Flash – Movie similarity evaluation

🎬 Purpose

To provide a fun and fast way to solve the classic “What should we watch?” dilemma.
